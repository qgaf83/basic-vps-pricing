## 买完之后：KiwiVM 面板能做什么

KiwiVM 是搬瓦工自己开发的管理面板，Basic 套餐的功能它全都覆盖：开关机、重装系统、紧急控制台（SSH 连不上时的最后手段）、rDNS 设置、快照、用量统计，还有完整的 API。对喜欢折腾的人来说，API 意味着重装系统、查流量这类操作都能脚本化。

备份和快照是两套并行的机制，容易混淆，分开说：

- **自动备份（Backups）**：系统免费自动执行，备份频率取决于你实际用了多少磁盘空间——占用越少备份越频繁，一般一周左右会有一份，系统大约保留 3 个时间点。
- **快照（Snapshots）**：手动创建，同样免费，默认保留 30 天，可以把其中 2 个设为永久保存。改动大配置之前先拍一个快照，是成本最低的保险。

一个细节：自动备份恢复时不能一键回滚，需要先把备份导入快照、再通过快照恢复，多一步但并不复杂。
